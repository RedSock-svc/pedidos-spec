# Glosario

El lenguaje del dominio: cada término significa lo mismo en la especificación, en el código y en las conversaciones. Ordenado alfabéticamente.

| Término | Definición | Sinónimos que no se usan |
|---|---|---|
| **Anonimizar** | Sustituir los datos que identifican a una persona por valores que no permiten saber de quién eran, de forma irreversible | Borrar, ocultar |
| **Catálogo** | Conjunto de productos que un cliente puede pedir | Tienda, inventario |
| **Cliente** | Persona identificada que hace pedidos | Usuario, comprador |
| **Importe total** | Lo que cuesta un pedido: precio unitario por cantidad (`RN-004`) | Total, precio del pedido |
| **Pedido** | Petición de un cliente de un número de unidades de un producto, que queda registrada con su importe | Orden, compra |
| **Pedido confirmado** | Pedido aceptado, con su stock ya descontado | Pedido aceptado, pedido completado |
| **Precio** | Lo que cuesta una unidad de un producto, en céntimos de euro | Coste, tarifa |
| **Producto** | Artículo del catálogo que se puede pedir | Artículo, item, referencia |
| **Stock** | Unidades de un producto disponibles para pedir | Existencias, inventario, disponibilidad |
| **Titular** | Cliente al que pertenece un pedido: el que lo creó (`RN-003`) | Propietario, dueño |
